# DataFest Project Workspace

This workspace is organized into a few main folders:

- `docs/` for writeups and participant documentation
- `notebooks/` for exploratory notebooks
- `scripts/` for reproducible analysis and dashboard generators
- `site/` for standalone HTML dashboard pages
- `eda_output/` for generated charts, CSV summaries, PDFs, and HTML reports

Most scripts can be run from `scripts/` and will still write outputs into `eda_output/`.
